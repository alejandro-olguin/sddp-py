# sddp-py
Native Python port of SDDP.jl - a package for solving multistage stochastic optimization problems using stochastic dual dynamic programming

## Reference

This project is a native Python port of the original SDDP.jl implementation by Oscar Dowson and contributors:

- Dowson, O., & contributors. SDDP.jl: A Julia package for solving multistage stochastic optimization problems using stochastic dual dynamic programming. https://github.com/odow/SDDP.jl
